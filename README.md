## 它能做什么

DSH 自带的右侧文档预览已经能打开工作区文件（Markdown、代码、PDF、Word/PPT、Excel/CSV、图片），并且会监听文件变化自动刷新。本插件补四块：

## 1. 划词工具条

在右侧预览里选中任意文字，浮出工具条：

- **复制**：复制选中文字。
- **引用提问**：把选中文字作为引用插入对话输入框（DSH 原生 quote），接着输入问题即可。
- **翻译**：调用当前默认模型做中英互译，译文直接在选区旁的浮窗里显示，不发送到对话。中文为主的选区译为英文，其余译为简体中文。

作用范围是右侧文档预览里的正文，不包括输入框和 HTML iframe 内部。

## 2. 跟随编辑

对话里 Agent 执行 `write`、`edit`、`str_replace_editor` 修改文件后，插件会自动在右侧打开这个文件的实时预览；预览自身的自动刷新会把后续改动同步过来。

右侧预览标题栏有一个「跟随编辑」小按钮，可以随时开关，状态存在浏览器本地。

## 3. 流式写入

Agent 调用 `write` 生成文件时，右侧浮动显示「正在写入」面板，内容随模型输出实时增长；`edit` / `str_replace_editor` 显示改动的旧/新片段。写盘完成后面板关闭，正式预览自动打开或刷新。

## 4. 音视频播放

工作区里的视频和音频在右侧直接播放，不再落到「不支持的文件类型」；走 Host 的鉴权字节流路由，拖动进度只取附近的字节，大文件也不受预览 32 MiB 整文件上限影响。视频没有音轨时会直接说明，而不是留一个点了也没用的静音按钮。

## 使用

### 1. 打开右侧预览

**方式 A：快捷键**

- macOS：`Cmd+P`
- Windows / Linux：`Ctrl+P`

焦点在会话里时，会在右侧打开「文件」页。如果快捷键被浏览器的打印快捷键占用，改用下面的方式 B。

**方式 B：从右侧栏进入**

1. 先把右侧 Sidebar 展开（最右缘的细条 / 会话右上角的侧栏按钮）。
2. 点 tab 条最右端的「+」打开引导页（如果该格已经有引导页，直接在其中选「文件」）。
3. 文件页左侧是当前会话的工作区目录树，点任意文件即可预览。

**方式 C：从聊天里的文件入口进入**

- **交付文件卡片**（`present`）：点卡片正文，右侧打开实时预览；卡片右侧的分体按钮是用本机应用打开。
- **行内文件链接**：回复里被点名的产出文件路径（代码样式）可以直接点，右侧打开预览。
- **改动文件卡片**：点某一行打开的是这一轮的 **diff review**（改动对比快照），不是文件的实时内容；要看实时内容，用文件页或交付卡片。
- **右键文件路径**：菜单里有「在侧边栏打开」/「在浮窗中打开」。

### 2. 看文件

- 预览头部会显示文件路径、文件类型图标、渲染器下拉（有多个渲染器时才出现）、重新加载、换行、打开方式，以及本插件的「跟随编辑」按钮。
- Markdown / 代码 / 纯文本按页加载；滚到底或点「加载更多」。
- PDF / Office（转 PDF）在底部悬浮缩放控件里选「适应宽度 / 25% / 50% / 100% / 150% / 200%」；PDF 可以选中文字。
- Excel / CSV 是表格视图，可切纯文本；只读，不重新计算公式。
- 视频 / 音频打开即播放；控制条提供播放、进度、音量、倍速与全屏，拖动进度只读取目标附近的字节。
- 预览旁边可以打开工作区目录树（头部按钮），点树里的文件会替换当前预览 tab。

### 3. 划词工具条

在预览正文里选中文字，浮出三个动作：

- **复制**：复制选中文字。
- **引用提问**：把选中文字作为引用块插入对话输入框，光标回到输入框；接着输入问题发送即可。引用块可以单独删掉。
- **翻译**：在选区旁弹出翻译卡片，显示「翻译中…」→ 译文；可**复制译文**、失败可**重试**、右上角关闭；按 `Esc` 或点卡片外部也会关闭。翻译只做中英互译：中文为主的选区译成英文，其余译成简体中文，结果不写入对话。

作用范围是预览的正文内容。预览头部的路径、输入框、HTML 预览的 iframe 内部、Excel 的单元格选择不会触发这个工具条。

> Agentero Vault 里的 PDF 会由 agentero 自己的 PDF tab 接管，显示它自己的划词工具条（高亮/批注/翻译/提问）；工作区里不在 Vault 的 PDF 才走自带预览 + 本插件工具条。

### 4. 音视频播放

- 点开 `mp4` / `m4v` / `webm` / `mov` / `ogv`、`mp3` / `wav` / `m4a` / `aac` / `flac` / `opus` / `ogg` 等音视频文件即可播放；视频默认静音自动播放，元信息行的「取消静音」或控制条音量图标可开声，控制条另有进度、全屏。
- 播放器下方显示类型、体积、时长；文件被重新渲染后出现「文件已更新 · 加载新版本」，点它从当前位置附近继续播放，正在播放时不打断。
- 浏览器解不了码的容器（`mkv` / `avi` / `wmv` / `flv`、ProRes 等）显示可读的失败说明，并保留「打开方式」交给本机播放器。

### 5. 流式写入

Agent 调用 `write` 生成文件时，右侧会出现一个浮动的「正在写入」面板：

- 内容随模型输出实时增长，是**源码视图**；写盘完成后面板自动关闭，正式预览打开或刷新，此时才按 Markdown / 代码等正式渲染器显示。
- `edit` / `str_replace_editor` 显示「正在编辑」，并流式展示旧内容与替换后的新内容片段。
- 面板可以手动关闭；关闭只影响这一次写入，不改变文件内容。
- 不需要提前打开文件预览，面板会直接出现在右侧。

### 6. 跟随编辑

- 预览头部有一个「跟随编辑」小按钮（实时点图标），默认开启，状态存在浏览器本地。
- 对话里 Agent 成功执行 `write`、`edit`、`str_replace_editor` 后，插件会自动在右侧打开被改文件的实时预览；文件已经打开时，自带预览的自动刷新会把内容更新过来。
- 关掉「跟随编辑」后不再自动打开新文件，但已经打开的预览仍会自动刷新。
- 如果自动打开太频繁，关掉它即可；需要看某个文件时从文件页点开。

### 7. 常见问题

- **工具条没出现**：确认选的是预览正文；刷新一次页面（`Cmd+R`）；确认当前是自带文档预览，而不是 agentero 的 PDF tab。
- **翻译报错**：先在「设置 → 模型」选好默认模型；选区太长（超过 6000 字工具条不会出现，接口上限 8000 字）先缩短；provider 报错按卡片提示重试。
- **流式面板没出现**：确认 Agent 正在调用 `write` / `edit` / `str_replace_editor`；如果只是普通对话或读文件，不会出现。
- **自动打开太频繁**：关掉预览头部的「跟随编辑」。
- **内容没刷新**：点预览头部的重新加载；网络盘或虚拟文件系统可能不触发文件监听。
- **`Mod+P` 没反应**：用右侧栏「+」→「文件」，或先展开右侧栏。
- **视频黑屏或提示无法播放**：容器能识别不代表浏览器能解码，ProRes/HEVC/mkv 这类编码仍可能失败；换成 H.264/AAC 的 mp4 试，或点「打开方式」交给本机播放器。
- **视频没有声音**：先看播放器下方是否提示「这个视频没有音轨」——没有音轨的文件本来就没有声音可放，重新渲染时带上音轨即可；有音轨的视频点「取消静音」，或控制条上的音量图标开声。
- **播放中提示「文件已更新」**：文件正在被重新渲染，点「加载新版本」会从当前位置附近继续播放；不点则保持当前画面。

## 版本与更新

设置 → 插件 → 「版本更新」（插件管理器的插件详情页也有一份同样的面板）：

- **当前版本**：每次打开都重新读 `package.json`，本地把版本改成 0.2.1 后立即显示 0.2.1。
- **检查更新**：按安装来源去问 npm registry（默认官方源，插件管理器配了镜像就跟着走），结果缓存 10 分钟。
- **更新**：registry 安装且 npm 上有新版本时显示「更新到 vX.Y.Z」，走 DSH 插件管理器直接重装；装完提示「重启 DSH 生效」。
- **版本历史**：按发布时间倒序列出已发布版本，并附当前 `CHANGELOG.md` 里的更新说明；当前版本有「当前」标签。registry 连不上或尚未发布时退化为本地 `CHANGELOG.md`。
- **本地安装不提示更新**：`link:` / 文件夹安装显示「本地文件夹安装（改完插件目录后重新加载）」，因为这种安装的更新源是那个目录，不是 registry。改完目录后在插件页重新启用一次，或刷新页面 / 重启 DSH 即可加载新代码。

## 安装

从 npm 安装（发布后）：

```text
dsh plugin --profile desktop add dsh-file-agentero
```

或者在 DSH 的插件管理器里安装 `dsh-file-agentero@latest`。

本地开发时直接安装这个目录：

```text
plugin_manager install_bundle  <本目录绝对路径>
```

安装后当前 profile 的所有会话生效，重启后仍然保留。

## 边界

- 翻译只做中英互译，使用当前默认模型；结果只在浮窗里显示，不写入对话记录。
- 不做文件编辑，只做预览与引用；写文件仍由 Agent 的文件工具完成。
- 不复制文件内容到 Vault，不新增数据库，不改变 Host 的文件读取权限。
- HTML 预览是沙箱 iframe，划词工具条不进入 iframe 内部。
- 音视频只做播放，不做转码、剪辑、抽帧或字幕；能否播放取决于浏览器内置解码器。
- 没有音轨的视频会明确提示；有音轨但编码不受支持（如 AC-3）仍可能无声，本插件不做转码兜底。
- 媒体流路由只读、只服务视频/音频后缀，鉴权沿用当前浏览器的登录态，不额外开放文件读取权限。
